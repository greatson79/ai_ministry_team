# 교회 데이터 폴더

AI 팀이 참조하는 교회 기본 데이터를 이 폴더에 넣습니다.

## 파일
- `church-calendar.md` — 교회 절기·행사 일정
- `sermon-data.md` — 설교 본문·주제 계획

## 예시 (church-calendar.md)
```markdown
# 교회 절기·행사
- 3월: 사순절 시작
- 8월: 전교인 수련회
- 12월: 대림절·성탄
```

## 예시 (sermon-data.md)
```markdown
# 설교 계획
- 1월: 요한복음 강해 (시작)
- 부활주일: 부활 특별설교
```

이 폴더의 실제 콘텐츠는 `.gitignore`로 공개에서 제외됩니다.
